# Vision de Producto

**Status: Proposed**

Construir un CRM para fundaciones que centralice la informacion de donantes, socios y suscripciones procedente de plataformas de pago y reportes operativos. El CRM debe permitir consultar y gestionar esa informacion de forma comoda, trazable y segura, sin depender de la estructura particular de cada proveedor.

## Objetivos

1. Centralizar datos de socios desde APIs y reportes Excel.
2. Visualizar informacion centralizada para operacion diaria.
3. Gestionar suscripciones dentro de los limites autorizados por cada plataforma.
4. Crear reportes operativos, financieros y estrategicos.
5. Habilitar en una fase posterior modelos y proyecciones predictivas.

## Alcance actual observado

El repositorio ya ofrece consulta por canal, dashboards, autenticacion, permisos y trazabilidad de sincronizaciones. Este alcance operativo no equivale todavia a una ficha unica de donante entre plataformas.

## Identidad centralizada

**Status: TBD**

La estrategia para identificar y deduplicar socios entre plataformas no esta aprobada. Una ficha unificada exigira reglas de matching, manejo de conflictos, revision manual y gobierno de datos antes de cualquier merge automatico.
