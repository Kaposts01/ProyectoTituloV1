# Liquidacion

**Status: TBD**

LIQUIDACION se reserva como concepto para una agrupacion financiera informada por una plataforma o proceso de conciliacion. No existe un contrato transversal ni una entidad Core aprobada.

Antes de modelarla deben definirse periodo, fuente de verdad, comisiones, impuestos, reversos, conciliacion bancaria y relacion con cobros y pagos. Esta nota no prescribe campos ni comportamiento tecnico.
