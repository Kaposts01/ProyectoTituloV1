# SynkmetriX

Knowledge Base del proyecto SynkmetriX, CRM para centralizar socios, suscripciones, cobros, pagos e informacion proveniente de multiples canales.

## Proposito

SynkmetriX centraliza informacion de socios, donantes y suscripciones proveniente de plataformas de pago y reportes historicos. Permite consulta, gestion controlada, reportes y una futura fase de analitica.

## Estado actual

El proyecto cuenta con FastAPI, PostgreSQL, React/Vite, autenticacion y permisos, staging trazable por canal, sincronizaciones API para VirtualPOS, Toku y Payku, y carga Excel para TCH. La estrategia de identidad centralizada esta aceptada en ADR-001, pero su implementacion tecnica sigue pendiente.
