# Knowledge Base

`docs/` es la documentacion tecnica fuente de verdad y versionada del proyecto.

`knowledge/` es la capa navegable de Knowledge Base para Obsidian: indices, relaciones y conocimiento de alto nivel.

No dupliques documentacion tecnica innecesariamente. Cuando exista una fuente tecnica vigente, prefiere enlazar a `docs/`.

Las decisiones arquitectonicas formales permanecen en `docs/decisions/`.
