# Casos de revision de dashboards

| Solicitud | Evidencia esperada | Regresion que detectar |
| --- | --- | --- |
| Corregir churn del mes | Poblacion y formula explicitas; bajas del periodo contra base definida | Dividir bajas historicas por stock actual |
| Reporte actual muestra cero con archivo TCH de otro mes | Fecha de corte y disponibilidad visibles | Presentar periodo ausente como fallo de importacion o cero confirmado |
| Consolidar ingresos Toku y VirtualPOS | Hechos de pago verificables y unidades compatibles | Usar facturas como pagos o sumar intentos y pagos |

Ejemplo de activacion: "Explica y corrige la diferencia entre la tarjeta de recaudacion y su serie mensual". No activar para cambiar un icono del menu.
